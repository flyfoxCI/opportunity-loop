小红书小工具Xiaohongshu mini tools

Which small tools Xiaohongshu users pick up

Static, single-page tools that creators attach to their notes. The official boards rank them by users and 7-day activity. Casual games and tests lead, which makes this an early read on consumer tool demand in China.

No board imported yet

The official rankings only exist inside the Xiaohongshu app, so the radar reads a file you add. Open the 小工具 board in the app, then either type the rows into a CSV or send the screenshots to Claude Code and ask it to transcribe them.

  1. Save as data/xhs_tools/2026-11-17.csv (Top100) or 2026-11-17_new.csv (released today)
  2. Columns: rank,name,users,active_7d,category,note_url,author. Chinese headers such as 排名, 名称, 使用人数 also work; 1.2万 and 3k are read as numbers
  3. Run python -m radar collect --only xhs and python -m radar build, or push and let the daily job pick it up
