What it is

Widget Al-Qur’an: Ayat dan Doa is an Android Lifestyle app that puts Qur’anic verses, prayers, and Islamic quotes on Home Screen and Lock Screen widgets. It also offers Islamic-themed live and static wallpapers, allowing users to build a repeatable daily routine without repeatedly opening a separate app.
