If you build here

BuildBuild a Douyin-ready casual mini-game with one instantly visible mechanic, a themed reskin for a specific audience, and a complete free round before testing any paid unlock.

AvoidDo not clone the zombie theme or assume a one-day ranking jump proves the growth idea works; the causal evidence for all observed breakouts is weak.

  1. Ship one 15–30 second clip that opens on the mechanic's payoff and demonstrates the full core loop.
  2. Create distinct tracked links or campaign labels for each clip, then measure clicks, plays, and completed rounds for at least 72 hours.
  3. Interview or survey recent players about the first confusing or paywall-worthy moment, then place one optional unlock behind a tested progression point.
